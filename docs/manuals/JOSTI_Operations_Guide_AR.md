# دليل تشغيل جوستي

الإصدار 1.0.0 · 15 أكتوبر 2026 · شركة النقل الذكي · تنفيذ VEGA

## 1. المقدمة والنطاق

جوستي ينسّق نقل الحاويات المفسوحة من الموانئ إلى مستودعات التجار. يربط التاجر والمخلص الجمركي وشركة النقل والناقل الفرد والسائق والإدارة. جوستي لا يملك أسطولًا ولا يشغّله.

الوحدات المنفذة: واجهة REST على Bun وHono، وقاعدة PostgreSQL مع ترحيلات SQL، وتطبيق ويب للأدوار التشغيلية، ولوحة إدارة، وتطبيق Expo للجوال، وتخزين خاص للمستندات، ومسار الرحلة، وتحديثات الموقع، والتنبيهات داخل التطبيق، والتقييمات، والبلاغات، وسجلات رسوم المنصة.

المتصفحات المدعومة هي الإصدارات الحديثة من Chrome وEdge وFirefox وSafari، مع تطبيقي أندرويد وiOS عبر Expo. في الإنتاج يجب أن يعمل الاتصال عبر HTTPS.

غير المنفذ: الربط التلقائي مع فسح أو أي نظام حكومي، والرسائل القصيرة، وواتساب، والمزادات، ورحلات العودة، والصيانة، والتخزين، وتوقع الأسعار، والمحفظة، وبوابة الدفع. تأكيد السداد والتخليص والتسوية سجلات لأعمال تتم خارج جوستي.

## 2. التثبيت والتشغيل

يلزم Bun 1.3 أو أحدث. في الإنتاج يلزم خادم Linux وNginx وPM2 وPostgreSQL 15 أو أحدث، ويمكن استخدام PostgreSQL عبر Supabase.

من PowerShell على جهاز التطوير:

```powershell
cd C:\Users\admin\Downloads\JOSTI
bun install --frozen-lockfile
copy .env.example .env
bun run db:migrate
bun run dev
bun run --cwd web dev
bun run --cwd admin dev
```

الواجهة البرمجية على المنفذ 3000، وتطبيق الويب على 5173، ولوحة الإدارة على 5174. فحص الصحة: `GET /health`. فحص الجاهزية: `GET /ready`. بدون `DATABASE_URL` تستخدم البيئة المحلية قاعدة PostgreSQL مدمجة في `./data/pglite`. يجب تعيين `JWT_SECRET` بطول 32 حرفًا على الأقل، والقيمة الافتراضية في المثال مرفوضة.

إنشاء المدير يتم بكلمة مرور يختارها المسؤول ولا تُكتب في المستودع:

```powershell
$env:ADMIN_EMAIL="admin@example.com"
$env:ADMIN_PASSWORD="a-long-unique-password"
bun scripts/create-admin.ts
```

## 3. الإعداد

| المتغير | الغرض |
| --- | --- |
| DATABASE_MODE | `pglite` للتطوير و`postgres` للإنتاج |
| DATABASE_URL | سلسلة اتصال PostgreSQL |
| JWT_SECRET | سر الجلسات، 32 حرفًا على الأقل |
| CORS_ORIGINS | أصول الويب والإدارة |
| STORAGE_LOCAL_DIR | الملفات الخاصة عند عدم ضبط Supabase |
| SUPABASE_URL والمفتاح والدلو | تخزين خاص اختياري |
| MAP_TILE_URL | خرائط OpenStreetMap افتراضيًا |
| FCM_SERVER_KEY وAPNS | إشعارات الجهاز عند توفرها |
| ALLOW_DEV_RESET_TOKEN | رمز استعادة للتطوير فقط، ويمنَع في الإنتاج |

رسم الرحلة الافتراضي 50 ريالًا. الفترة المجانية غير مفعّلة حتى يضبطها مسؤول المالية بتاريخ بداية ونهاية وقاعدة أهلية. الويب يستخدم ملفات ارتباط HttpOnly، والجوال يستخدم رمز Bearer.

## 4. الأدوار

### التاجر

يرفع السجل التجاري والشهادة الضريبية والعنوان الوطني وشهادة الآيبان، وينتظر التحقق ثم التفعيل. يختار المخلص الافتراضي أو مخلصًا آخر لكل طلب. السعر المقترح غير ملزم. بعد الإفراج يختار مرشحًا واحدًا وهذا تعيين نهائي. يقيّم الناقل بعد التسليم.

### المخلص الجمركي

يرفع رخصة النشاط والسجل ومستند حساب فسح والعنوان الوطني. مراجعة فسح يدوية. يحدد السعر المعتمد ويسجل السداد الخارجي والتصاريح ويرفق دليل التخليص ويؤكد الجاهزية. الجاهزية لا تعرض الطلب على الناقلين. يمكنه إعادة الطلب للتصحيح.

### شركة النقل

تضيف المركبات والسائقين وتربطهم وتحدد التوفر. الرد على الطلب المفرج عنه ترشيح فقط. تقيّم التاجر بعد التسليم. تشارك رمز الانضمام مع السائقين.

### الناقل الفرد

حساب ناقل مع ملف سائق لنفس الشخص. لا يضيف سائقين منفصلين. ينفذ الرحلة بنفسه بعد الاعتماد.

### السائق

ينضم لشركة النقل برمز الانضمام أو ينشئه الناقل. يرى رحلاته فقط. يرفع صورة التحميل وإذن التسليم ويرسل الموقع.

### مسؤول التحقق

يراجع المستندات ويضبط حالات التحقق والتحديث والإيقاف. لا يفعّل الحساب ولا يفرج الطلب.

### مسؤول العمليات

يفرج الطلبات ويراقب الرحلات ويغلق الرحلة المسلّمة ويعالج البلاغات. لا يغيّر سياسة الرسوم.

### مسؤول المالية

يضبط الرسم والفترة المجانية ويسجل التسوية الخارجية. لا يفرج الطلبات.

### المسؤول العام

يجمع الصلاحيات ويمكنه التفعيل وقراءة سجل التدقيق. لا يغيّر حالته أو صلاحياته بنفسه.

## 5. مسار النقل

1. التاجر ينشئ الطلب فتدخل الحالة إلى التخليص الجمركي.
2. المخلص يثبت السعر ويؤكد الجاهزية. الحالة تصبح جاهزة للمراجعة الإدارية.
3. الناقل لا يرى الطلب قبل الإفراج.
4. مسؤول العمليات أو المسؤول العام يفرج الطلب.
5. الناقل المؤهل يقبل السعر المعتمد ويصبح مرشحًا.
6. التاجر أو المخلص المعين يؤكد مرشحًا واحدًا داخل معاملة واحدة. يُنشأ مرجع مثل `JST-000001` بناقل وسائق ومركبة وسعر واحد. الإلغاء العادي يتوقف.
7. السائق يسير: في الطريق إلى الميناء، الوصول، التحميل، بدء الرحلة، في الطريق، الوصول للوجهة، تم التسليم.
8. التحميل يتطلب صورة. التسليم يتطلب اسم المستلم والوقت وإذن التسليم. صورة التحميل لا تغني عن إذن التسليم.
9. المدير المخوّل يغلق الرحلة. يُسجل رسم 50 ريالًا مرة واحدة ما لم تُعفِ الفترة المجانية المعتمدة الرحلة.
10. التقييم متاح بعد التسليم. البلاغ لا يلغي الرحلة ولا يضيف غرامة.

## 6. العمليات الإدارية

العنوان المحلي `http://127.0.0.1:5174`. تشمل البحث، واعتماد المستندات، وتفعيل المركبة والسائق بعد اكتمال مستنداتهما، والإفراج، وإغلاق الرحلة، والبلاغات، وتصدير الرحلات والرسوم، وسجل التدقيق. الخادم يرفض أي إجراء لا تملكه الصلاحية حتى لو ظهرت الشاشة.

## 7. تشغيل الويب والجوال

```powershell
bun run build:web
bun run build:admin
```

من مجلد `mobile`:

```powershell
$env:EXPO_PUBLIC_API_URL="https://api.example.com"
bun run start
bun run export:android
bun run export:ios
```

يمكن على ويندوز تصدير حزم أندرويد وiOS. بناء تطبيق iOS الموقّع يحتاج macOS. بناء أندرويد على جهاز يحتاج Android Studio أو EAS. التطبيق يطلب الكاميرا والإشعارات والموقع مع شرح. التتبع في الخلفية أثناء الرحلة النشطة فقط، ويتوقف إذا أغلق النظام التطبيق بالقوة. لم يتم النشر على المتاجر.

## 8. استكشاف الأخطاء

- رفض التشغيل لنقص الإعداد: عيّن `JWT_SECRET` وفي الإنتاج `DATABASE_URL`.
- فشل الترحيل: تأكد من اتصال PostgreSQL وصلاحية المستخدم. لا تحذف قاعدة الإنتاج.
- 401 يعني إعادة الدخول. 403 يعني أن الحساب غير نشط أو موقوف أو بلا صلاحية. 404 لسجل طرف آخر سلوك متوقع.
- رفض الملف: PDF أو JPEG أو PNG أو WebP حتى 10 ميغابايت. صورة التحميل يجب أن تكون صورة.
- الخريطة فارغة: لا يوجد تحديث موقع خلال 24 ساعة.
- الإشعار skipped: لا توجد بيانات مزود. سجل قاعدة البيانات ليس تسليمًا.
- فشل بناء الجوال: نفّذ `bun install` داخل `mobile` وتأكد من إصدار Expo.

## 9. الاختبار والقبول

```powershell
bun run typecheck
bun run lint
bun test
bun run build
```

رحلة القبول تسجل تاجرًا بمخلص افتراضي، وتثبت أن الناقل لا يرى الطلب قبل الإفراج، وأن الاختيار المتزامن ينتج رحلة واحدة، وأن نقص الإثبات يمنع التقدم، وأن الرسم يُسجل مرة واحدة، وأن اختيار مخلص مختلف يُحترم. تغطي أيضًا قيد الناقل الفرد والإيقاف وتكرار التقييم ورمز إشعار مرفوض.

النتائج الفعلية في `docs/TEST_REPORT.md`. تسليم الإشعار على جهاز حقيقي، والتوقيع للمتاجر، ومشروع Supabase مستضاف لم تكن متاحة.

## 10. قائمة الإطلاق

- أنشئ المدير بكلمة مرور فريدة.
- فعّل HTTPS ولا تضع الأسرار في المستودع أو هذا الدليل.
- خذ نسخة احتياطية واختبر الاستعادة.
- اجعل التخزين خاصًا.
- تأكد أن مسؤول المالية لا يستطيع الإفراج.
- اضبط عنوان الإنتاج في تطبيق الجوال.
- لا تضبط مفاتيح الإشعارات إلا بمفاتيح حقيقية.
- راقب `/health` و`/ready`.
- لا تفعّل الفترة المجانية قبل اعتماد قاعدتها.
